## 🚀 Projects

### 🍖 HoneyBaked Ham — Website Re-platform
`Next.js` `Contentful` `Azure` `Storybook`
- Owned the complete **global navigation system** for a legacy Backbone.js → Next.js re-platform — accessible header nav bar with hover and click-lock states, rewards hovercard, category panel, and mobile drawer with slidable sub-categories — as one of **~12 contributors on a 1,166-commit monorepo**.
- Replaced hardcoded CTAs with a dynamic adapter preserving accessibility attributes; published Storybook as a static site to Azure Blob Storage and authored ADRs on breakpoints and design-token guidelines.

### 🧶 Loom — AI Design-to-Code Platform
`Next.js` `TypeScript` `NextAuth v5` `Okta OIDC` `SSE` `npm`
- Sole author of `@gale-org/loom-cli` (**89% of commits**), a published npm package installing design-system components from a registry; owned the full release lifecycle across 4 releases and built a non-blocking background update checker on a detached worker, at a **1:1 source-to-test file ratio**.
- Primary contributor to the platform frontend (**73% of commits, +39.7K lines**): implemented **Server-Sent Events** end to end — proxy route, reusable hooks, live progress UI — plus multi-tenant RBAC and Okta OIDC SSO on NextAuth v5.
- Authored **7 of 8 architecture decision records**, including an SSE snapshot bridge reconciling streamed updates against cached state without race conditions, and a deferred account-switching design eliminating cross-tenant errors.
- Built the architecture **proof-of-concept** establishing the registry contract — file convention, build step, output schema — adopted by the production design-system repositories.

### ✉️ Weave — Enterprise Email Automation Platform
`Next.js 15` `React` `Zustand` `Ant Design` `Salesforce Marketing Cloud`
- Primary contributor (**72% of commits**) on a greenfield build; delivered a 5-step Figma-to-HTML email workflow with gated progression, a dual-mode editor with live preview, and Salesforce Marketing Cloud export.
- Led the migration from a Vite + React Router SPA to **Next.js 15** post-MVP, introducing server-side routing, NextAuth authentication, and **50+ typed API route handlers**.
- Built the Content Reference File system with live Google Sheets sync, **reducing manual QA effort by roughly 80%** and cutting production cycles from days to hours with zero major production incidents.

### 🧭 Navigator — Multi-Platform Advertising Campaign Management
`Next.js` `React Query` `Material-UI` `TypeScript`
- Delivered **96 features and 115 fixes** through a full platform revamp spanning two stack generations — **508 commits across 1,913 files (+70.5K lines)** — the longest-running engagement of the four.
- Built **19+ Google advertising workflows** (Display, Search, YouTube, DV360) plus Meta and TikTok integrations.
- Designed the budget management system with real-time allocation sliders and multi-currency support.
